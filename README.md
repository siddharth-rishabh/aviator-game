# Aviator Multiplayer Crash Game 
A real-time multiplayer Aviator-style crash game built using React, Node.js, Socket.io, MongoDB, JWT authentication, and AWS EC2 deployment.
## Live Demo http://15.134.234.250

## Features 
- Real-time multiplayer gameplay
- Live multiplier updates
- Plane animation 
- Bet & Cash Out system
- JWT authentication
- Wallet management 
- Round history 
- HMAC-SHA256 crash logic 
- AWS deployment

## Tech Stack
### Frontend 
- React.js 
- Tailwind CSS
- Socket.io 
### Backend 
- Node.js
- Express.js
- Socket.io
- JWT
- MongoDB

- AWS
